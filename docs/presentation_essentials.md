# 발표 시 꼭 언급해야 할 항목 정리

실제 코드(`scenes/`, `entities/`, `core/`, `world/`) 기준으로 정리. `README.md`는 예전 버전(2스테이지, 자체 AABB 물리) 설명이라 **현재 구현과 다릅니다 — 발표 전에 README를 갱신하거나, 최소한 발표 중엔 README를 인용하지 마세요.** (아래 ⚠️ 참고)

---

## 1. 한 줄 소개 (필수)

> "위험을 감수하고 도전하다가, 시간을 되감아 다시 시도할 수 있는 2D 플랫포머."

## 2. 핵심 메커닉 — 시간 되감기 (필수, 가장 중요)

- **Z**: 최근 N프레임(약 2초, `REWIND_FRAMES`) 되감기
- **X**: 스테이지 시작 지점까지 전체 되감기
- **횟수 제한**: 스테이지당 최대 5회 (`MAX_REWIND_COUNT`) — 무한정 쓸 수 없다는 점이 전략성을 만든다
- **무엇이 되감기되는가**: 플레이어 위치/속도/HP, 적 위치/생존 상태. **스위치는 예외 — 한 번 켜진 스위치는 되감기해도 꺼지지 않음** (최근 변경, 의도된 디자인 결정)
- **구현 방식**: 매 프레임 `GameState` 스냅샷을 `TimeStack`(스택)에 push, 되감기 시 pop해서 복원

## 3. 게임 구성 (필수)

- 총 4스테이지: **Normal → Switch → Golem → Boss**
- 맵은 직접 코드로 좌표를 박아넣은 게 아니라 **Tiled 에디터로 만든 `.tmx` 파일을 `pytmx`로 로드** — 맵 디자인과 코드가 분리되어 있다는 점은 강조할 만한 포인트
- 스위치 퍼즐(스테이지 2): 스위치 A/B를 모두 활성화해야 게이트가 열림
- 보스(스테이지 4, Time Guardian): HP에 따라 Phase 1→2→3 전환, **Phase 3에서는 보스도 플레이어처럼 시간을 되돌려 체력을 회복** — "플레이어만의 능력이 아니다"라는 컨셉적 재미 포인트

## 4. 기술 스택 (필수)

- Python + **Pygame** (렌더링/입력/사운드)
- **Pymunk** (물리 엔진) — 중력, 점프, 충돌을 직접 구현하지 않고 물리 엔진에 위임
- **Pytmx** + Tiled — 타일맵 로딩

## 5. 아키텍처 한 줄 요약 (선택, 시간 있으면)

- `scenes/` (start/game/end 씬 전환) → `world/` (스테이지·타일) → `entities/` (player/enemy/boss) → `core/` (시간 되감기 스택, 게임 상태)
- 씬 전환: `start → game(stage1~4 순차) → end → start`

## 6. 개발 중 부딪힌 기술적 문제와 해결 (필수 — 가장 어필되는 부분)

**"옆벽을 뚫고 지나가는 버그"** — 발표에서 과정을 설명하면 좋은 소재:

- 원인: 매 프레임 입력으로 속도를 강제로 덮어쓰다 보니, 물리 엔진(pymunk)의 충돌 보정이 따라가지 못해 벽에 천천히 파고들다가 결국 통과해버림
- 해결: 물리 엔진 충돌에만 의존하지 않고, 사각형(rect) 기반으로 한 번 더 옆벽 충돌을 직접 검사·보정하는 안전장치(`resolve_wall_collisions`)를 추가
- 스위치로 열리는 게이트에도 같은 문제가 있어서 추가로 수정함 — "한 번 고쳤다고 끝이 아니라 비슷한 케이스를 더 찾아서 고쳤다"는 디버깅 과정 자체가 좋은 발표 소재

## 7. 결과 화면 / 평가 시스템 (필수)

- 클리어 시 클리어 타임 + 되감기 사용 횟수 표시
- **별점**: 되감기를 적게 쓸수록 별이 많음 (1회 이하=★★★, 3회 이하=★★☆, 그 이상=★☆☆) → "되감기는 안전망이지만, 잘 쓸수록 더 좋은 평가를 받는다"는 밸런스 메시지

## 8. 데모 시연 (필수, `docs/demo_script.md` 참고)

- 타이틀 → 스테이지1(기본 액션+Z) → 스테이지2(스위치 퍼즐) → 스테이지3(X 전체 되감기) → 스테이지4 보스(보스의 타임 리버스) → 결과 화면
- 발표 시간이 짧다면 **스테이지 2(스위치)와 스테이지 4(보스 타임 리버스)** 두 곳이 메커닉을 가장 잘 보여주는 구간이므로 우선 시연

## 9. 한계 / 향후 개선 (질문 대비, 솔직하게 준비)

- 현재 4스테이지로 콘텐츠 분량이 많지 않음
- 적 AI는 단순 정찰 패턴 (추격/원거리 공격 없음)
- 보스 패턴이 3가지(wave/freeze/afterimage)로 한정적
