## 개요

**Time Backer**는 시간 되감기 메커니즘을 핵심으로 하는 2D 플랫포머 게임입니다. 플레이어는 위험한 장애물과 적들을 피하면서 스테이지를 클리어해야 하며, 실수했을 때 시간을 되돌려 다시 시도할 수 있습니다.

### 주요 컨셉

- **시간 되감기**: 게임 상태를 이전 시점으로 되돌릴 수 있는 독특한 메커니즘
- **전략적 플레이**: 제한된 되감기 쿨다운을 고려한 신중한 플레이 필요
- **보스전**: 2단계 패턴을 가진 도전적인 보스 전투

---

## 게임 특징

### 🕐 시간 되감기 시스템

- **단계 되감기 (Z키)**: 한 단계씩 과거로 되돌아감
- **전체 되감기 (X키)**: 저장된 가장 오래된 시점으로 되돌아감
- **쿨다운 시스템**: 3초(180프레임) 쿨다운으로 남용 방지
- **시각 효과**: 되감기 시 화면 플래시 효과 (파란색/보라색)

### 🎮 게임플레이

- **2개의 스테이지**: 일반 스테이지 + 보스 스테이지
- **적 AI**: 정찰 패턴을 가진 적 캐릭터
- **보스 전투**: 2단계 패턴과 돌진 공격을 가진 보스
- **체력 시스템**: 플레이어 HP 3, 피격 시 무적 시간 제공
- **물리 엔진**: 중력, 점프, 충돌 처리

## 핵심 시스템

### 1. 시간 되감기 시스템 (`core/`)

#### `TimeStack` 클래스

게임 상태를 스택으로 관리하여 시간 되감기 구현

```python
- push(state): 현재 상태 저장
- pop(): 마지막 상태 복원 (1단계 되감기)
- pop_all(): 가장 오래된 상태 복원 (전체 되감기)
- peek(): 마지막 상태 확인 (복원하지 않음)
```

#### `GameState` 데이터 클래스

저장되는 게임 상태 정보:

- 플레이어 위치 (x, y)
- 플레이어 속도 (vx, vy)
- 플레이어 HP
- 되감기 카운트
- 적 상태 리스트 (`EnemyState`)
- 보스 상태 (`BossState`, 선택적)

**스냅샷 주기**: 6프레임마다 자동 저장 (60 FPS 기준 0.1초)

### 2. 물리 시스템

#### 중력 및 이동

- **중력**: 0.6 (매 프레임 vy에 가산)
- **점프력**: -13 (위쪽 속도)
- **이동 속도**: 4 (좌우 이동)

#### 충돌 처리

- **수평 충돌**: 벽에 막힘
- **수직 충돌**: 바닥 착지, 천장 충돌
- **적 충돌**: 밟기 vs 피격 판정
- **보스 충돌**: 밟기 공격 vs 피격

### 3. 씬 관리 시스템 (`main.py`)

게임은 3개의 씬으로 구성:

1. **StartScene**: 타이틀 화면, 조작법 표시
2. **GameScene**: 실제 게임플레이
3. **EndScene**: 승리/패배 화면

씬 전환 흐름:

```
Start → Game (Stage 1) → Game (Stage 2/Boss) → End → Start
```

## 게임 요소

### 플레이어 (`entities/player.py`)

#### 속성

- **크기**: 24×30 픽셀
- **최대 HP**: 3
- **무적 시간**: 피격 후 60프레임 (1초)
- **시각 효과**: 피격 시 깜빡임

#### 기능

- 좌우 이동 및 점프
- 지형 충돌 처리
- 피격 및 사망 처리
- 상태 저장/복원 (시간 되감기용)

### 적 (`entities/enemy.py`)

#### 속성

- **크기**: 24×28 픽셀
- **이동 속도**: 1.5
- **정찰 범위**: 4타일 (128픽셀)

#### 행동 패턴

- 시작 위치 기준 좌우 정찰
- 범위 초과 시 방향 전환
- 중력 적용 및 지형 충돌
- 플레이어 밟기 시 사망

### 보스 (`entities/boss.py`)

#### 속성

- **크기**: 48×52 픽셀
- **최대 HP**: 5
- **2단계 패턴**:
  - **1단계** (HP 5~3): 느린 정찰 (속도 2.0)
  - **2단계** (HP 2~0): 빠른 정찰 + 돌진 공격 (속도 3.8)

#### 공격 패턴

- **정찰**: 7타일 범위 좌우 이동
- **돌진 공격** (2단계):
  - 60프레임 경고 (노란색 깜빡임)
  - 플레이어 방향으로 고속 돌진 (속도 11)
  - 쿨다운: 240프레임 (4초)
  - 충돌 시 튕겨나감

#### 시각 효과

- 1단계: 빨간색
- 2단계: 주황색 (분노)
- 돌진 중: 주황색
- 피격 시: 흰색 깜빡임
- 돌진 경고: 노란색 테두리

### 타일 시스템 (`world/tile.py`)

#### 타일 종류

1. **Ground (1)**: 일반 지형 - 회색 블록
2. **Spike (S)**: 가시 함정 - 빨간 삼각형, 접촉 시 피해
3. **Exit (E)**: 출구 - 초록색, 스테이지 클리어

**타일 크기**: 32×32 픽셀

## UI 요소

### HUD (게임 중 표시)

1. **HP 표시**: 좌상단, 하트 3개
2. **되감기 쿨다운 바**: 화면 중앙 상단
   - 준비 완료: 청록색 "REWIND READY"
   - 쿨다운 중: 파란색 + 남은 시간 표시
3. **조작 힌트**: 우상단 "[Z/X] Rewind [R] Restart"
4. **보스 HP 바** (스테이지 2): 화면 하단 중앙
   - 1단계: 빨간색
   - 2단계: 주황색

### 시각 효과

- **되감기 플래시**:
  - 단계 되감기: 파란색 (40, 80, 220)
  - 전체 되감기: 보라색 (80, 40, 180)
  - 텍스트: "◄◄ REWIND" / "◄◄◄ FULL REWIND"

- **결과 오버레이**:
  - 스테이지 클리어: "STAGE CLEAR!" (청록색)
  - 게임 클리어: "VICTORY!" (청록색)
  - 게임 오버: "GAME OVER" (빨간색)

## 승리/패배 조건

### 승리

- **스테이지 1**: 출구 타일에 도달
- **스테이지 2**: 보스 HP를 0으로 만듦

### 패배

- 플레이어 HP가 0이 되고 되감기 쿨다운 중
- 맵 아래로 떨어짐 (y > 맵 높이 + 100)

### 자동 되감기

- 사망 시 쿨다운이 없으면 자동으로 1단계 되감기 실행
- 쿨다운 중이면 게임 오버
